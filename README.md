# Resume Matcher

A free AI career assistant. Add your resume and a job description, and it helps you prepare for that job.

## Features

- **Match score**: a score out of 100, matched and missing skills, stronger resume lines, a new summary and a cover letter
- **ATS check**: whether resume-screening software can read your resume properly
- **Tailored resume**: your resume rewritten for the job, downloadable as PDF
- **Mock interview**: 5 questions for the role, with a score, feedback and a model answer for each
- **Learning plan**: a 7-day plan for your missing skills
- **Messages**: a LinkedIn note, a recruiter message and a thank-you email
- **Job link import**: paste a job link instead of the description
- **Private history**: past results are saved only in your own browser
